# Nexus Longwave .10

The LAN browser panel picker now covers all 18 native pop-out types. POTA has
band and mode filter buttons; these filter the list without retuning the rig.
The top bar opens browser sharing from any main application screen. The short
address and eight-digit access code are unchanged.

Additional browser views are receive-only monitors, not interactive copies of
the transmit cockpits. Spots and receive memories offer deliberate listen
actions. Other views show contest and club status, activation counts, satellite
passes, DXpedition windows, heard stations, a station map, an audio waterfall,
and incoming/latest SSTV pictures. Tables are bounded to 200 displayed entries.

Use the external-link icon to open another panel in a separate browser tab.
Each tab authenticates independently. Manual refresh retains access and filters.
Hidden panels pause their data polling until visible again.

Browser actions cannot key the radio, arm digital transmission, start a QSO,
edit the log, tune the ATU, or start automatic Doppler tuning. Sharing remains
opt-in, unencrypted HTTP for a trusted private LAN; do not expose it online.

Longwave integration, IC-7300 controls and desktop microphone routing are
retained. The .9 branch and package remain available for rollback.
